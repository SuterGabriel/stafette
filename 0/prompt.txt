Worauf ihr achten müsst: Gradphone ist auf gpt-4o-mini von OpenAI eingestellt. Wenn ihr das so laufen lasst, telefoniert euer Agent mit OpenAI statt Gemini, und DeepMind fällt raus. Ihr müsst das in der .env auf Gemini umstellen:

LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_MODEL=gemini-3.6-flash
OPENAI_API_KEY=<euer Gemini-Key vom Hackathon-Account>

Der Variablenname heisst zwar OPENAI_API_KEY, aber der Inhalt ist euer Gemini-Key. Gemini bietet eine OpenAI-kompatible Schnittstelle an, darum funktioniert das ohne Umbau.

Zur Sicherheitswarnung: Die betrifft die Next.js-Version, die ich eingetragen habe. Für eine lokale Demo ist das kein akutes Risiko, aber da ihr das Repo öffentlich auf GitHub habt, behebt ihr es besser gleich. Nicht npm audit fix --force ausführen, das kann Versionen über grosse Sprünge hochziehen und Dinge kaputt machen. Stattdessen:

Im Terminal den Server stoppen mit Ctrl+C.
Dann:
powershell
npm install next@15

Das holt die neueste gepatchte 15er-Version.

Wieder starten:
powershell
npm run dev

Danach committen (in einem zweiten Terminal-Fenster oder nach Ctrl+C):

powershell
cd C:\stafette
git status

Prüfe kurz, dass node_modules und .next nicht in der Liste stehen (die .gitignore im Dashboard-Ordner sollte das abfangen). Dann:

powershell
git add .
git commit -m "Dashboard: patient app and doctor handover view (Next.js)"
git push

Wenn localhost:3000 gut aussieht, ist der Frontend-Teil erledigt, und wir gehen an Gradphone und das Backend.
